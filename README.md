# HB-Electronics Gas Alert System v5.0

**Independent Android v5.0 project.** Product code: `hb-gas-alert-v5`. This Android app has its own application ID (`nl.hbelectronics.gasalertv50`) and Android data, so it can be installed alongside the original v3.0 app. The existing ESP32-C3 v3 BLE protocol is preserved for hardware compatibility.

- Android: `android/`
- Firmware baseline (ESP32-C3 BLE compatible): `firmware/Gas_Alert_v3_0/`
- Build: GitHub Actions → **Build Gas Alert System v5.0 APK**
- Existing v3.0 project: https://github.com/Hans1972/Gas-Alert-System-v3.0

**License:** The Android licensing client targets HB-Electronics.nl with product code `hb-gas-alert-v5`. The product must exist on the server before activation can be tested. Licensing must never disable an active hardware alarm.
